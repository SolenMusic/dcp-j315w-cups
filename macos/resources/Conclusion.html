Driver installed

If the printer was discovered, choose DCP-J315W CUPS Driver when printing.

Otherwise, open System Settings → Printers & Scanners → Add Printer and select DCP-J315W CUPS Driver in the Use menu. For manual setup, run this in Terminal with your printer's network address:

sudo /Library/Printers/DCPJ315WCUPS/configure.sh --address PRINTER_ADDRESS

Default settings: A4, monochrome, 300 dpi. For artwork choose Colour and Fine (600 dpi). Load paper matching the selected size.
